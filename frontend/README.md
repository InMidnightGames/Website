# In Midnight Games frontend

React 19 + Vite + Tailwind v4. See the root [README](../README.md) for setup.

```
src/
  constants/    config.tsx (copy, links, feature flags, jobs), team.ts, navigation.ts, API clients
  common/       components, hooks, loaders (API + demo fallback), types, layout
  pages/        Home, Careers, DevBlog, Legal, Unsubscribe
  routes/       Router.tsx (routes for disabled pages are left out)
public/media/   optimized art, generated by `npm run assets`
```

Scripts: `npm run dev`, `npm run build`, `npm run lint`, `npm run assets`.
