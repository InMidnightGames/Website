# In Midnight Games website

The public site for **In Midnight Games**, laid out like the Fence site:

- `frontend/`: React 19, Vite, Tailwind v4. Home, careers, dev blog, legal and unsubscribe pages.

The backend (FastAPI + starlette-admin: dev blog posts, email campaigns, the admin dashboard) lives in its own repo,
[InMidnightGames/EmailCampaignBackend](https://github.com/InMidnightGames/EmailCampaignBackend).

## Quick start

To work against a local API, run the backend from its repo (see its README); it serves on http://localhost:8000.

```bash
cd frontend
npm install
cp .env.example .env
npm run dev            # http://localhost:5173
```

Without the backend running, the frontend falls back to the demo posts in
`frontend/src/common/data/mockData.ts` (set `VITE_USE_MOCK=true` to force it). A production build
with no `VITE_API_URL` also ships the demo posts, so the site deploys before the backend does.

## Where things live

| To change | Edit |
| --- | --- |
| Show / hide a page or a section, the floating CTA dock | `frontend/src/constants/config.tsx` (`features`) |
| Light / dark / system colour theme | `frontend/src/constants/config.tsx` (`siteConfig.theme`) |
| Discord, Patreon and social links, hero mission statement, copy | `frontend/src/constants/config.tsx` (`siteConfig`, `pagesConfig`) |
| Studio pillars | `frontend/src/constants/config.tsx` (`pillars`) |
| Open positions (no backend, edit the list) | `frontend/src/constants/config.tsx` (`jobs`) |
| Stream player (Twitch / YouTube toggle, channels, starting tab) | `pagesConfig.home.updates.live` |
| Team members | `frontend/src/constants/team.ts` |
| Art (hero, roster, pillars, key art, portraits) | `frontend/public/media`, regenerated by `npm run assets` |
| Fonts, colours for both themes | `frontend/src/index.css` (search `FONTS` / `TOKENS`) |
| Torn-paper edge shapes | `frontend/scripts/ragged-edges.mjs`, pasted into `index.css` |
| Dev blog posts | the backend admin: Dev blog |

## Art

Source art is too large for the repo (the roster PNG is 13500px wide). Convert it to web-sized WebP with:

```bash
cd frontend
ASSETS_DIR="D:/Personal/Work/IMG/Website Assets/Website Assets" npm run assets
```

See `frontend/scripts/optimize-assets.mjs` for the file list and output names.

## Deploying

`.github/workflows/main.yml` builds `frontend/` and publishes it to GitHub Pages on every push to `main`.
Set the repository variables `VITE_CONTACT_API_URL` and, once the backend is hosted, `VITE_API_URL`.
